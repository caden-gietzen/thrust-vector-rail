# Project Overview

This project is a one-dimensional thrust-vector rail system used to study actuator modeling, system identification, and feedback control.

## Purpose

The purpose of this project is to create a physical test platform for learning and demonstrating practical controls engineering. The system uses a motor and servo-controlled thrust vector to move and stabilize a cart on a linear rail.

## Core Engineering Areas

- Embedded control
- Sensor integration
- Actuator characterization
- System identification
- Feedback control
- Experimental validation

## Current Development Stage

The project is currently in early experimental development. Initial work is focused on reliable sensor measurement, thrust characterization, servo behavior, and simple stabilizing control.
