# Thrust Vector Rail

Experimental thrust-vector rail platform for system identification, actuator modeling, and feedback control.

## Goals

- Identify motor and thrust dynamics
- Identify servo angle dynamics
- Measure rail position with a quadrature encoder
- Build a usable dynamic model
- Design and test feedback controllers
- Document the engineering process from hardware testing to control implementation

## Repository Structure

- firmware — Microcontroller and embedded control code
- analysis — MATLAB and Python scripts for system identification and data analysis
- data — Experimental data
- docs — Engineering notes and documentation
- plots — Generated figures
